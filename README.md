# 🍡 Mochi — AAC Communication App

A free, accessible tap-to-speak communication tool built for non-verbal and minimally verbal users, starting with autism-related communication support needs.

**Live:** [mochi.kadowebstudio.com](https://mochi.kadowebstudio.com)

---

## What is Mochi?

Mochi helps non-verbal and minimally verbal users communicate through a symbol-based board. Users tap symbols to build phrases, which are then spoken aloud using the browser's built-in text-to-speech engine.

No downloads. No subscriptions. No accounts required. Always free.

---

## Features

- 🗣️ **Tappit Board** — tap symbols to build and speak phrases
- 🆘 **Quick Tappit** — instant one-tap emergency buttons (Help, Bathroom, Break)
- 🎵 **Rhymes Corner** — nursery rhymes for kids
- ✏️ **Drawing Area** — full screen canvas for self-expression
- 🌿 **Calm Corner** — breathing exercises, bubble visuals, color modes and sounds
- 👤 **Multiple Profiles** — personalized settings per user, stored locally
- 🎓 **Learning Mode** — every tap speaks the word immediately
- 🔊 **Voice Picker** — select preferred voice from available system voices
- 📴 **Offline First** — core communication works without internet
- 🎨 **5 Themes** — Blue, Pink, White, Dark, Energy

## Getting Started

### Prerequisites

- Node.js v20+
- Python 3.13+
- PostgreSQL
- pipenv

### Installation

```bash
# Clone the repo
git clone https://github.com/Diegosuna-84/Mochi

# Install frontend dependencies
cd Mochi
npm install

# Install backend dependencies
pipenv install
```

### Running locally

```bash
# Start frontend
npm run dev

# Start backend
pipenv run python src/app.py
```
